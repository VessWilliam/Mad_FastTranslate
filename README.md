# Mad FastAPI & ArgosTranslate API 🧸

A Translate API built with FastAPI & AgosTranslate.

Supports: English (en), Japanese (ja), Chinese (zh).

## Tech Stack 
- 🌀 Python 3.12.1
- 🧠 fastapi
- 📦 Uvicorn
- 🐕 ArgosTranslate
- 👾 LangDetect
- ⚠️ Pydantic

## Feature 
- 🔤 Auto language detection
- 🌍 Supports EN ⇄ JA ⇄ ZH
- 📦 Offline translation using Argos models
